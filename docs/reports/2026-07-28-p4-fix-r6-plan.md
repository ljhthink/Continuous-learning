## 一、问题清单

### 1.1 编译器警告 `#problem:The compiler option ...`

- **现象**：TRAE IDE 持续报告编译器选项警告，跨多轮修复未消除
- **诊断**：`tsconfig.json` 中 `useDefineForClassFields: true` 与 `target: ES2022` 冗余（ES2022 默认启用该选项）。IDE 提示该选项多余。
- **修复**：移除显式 `useDefineForClassFields: true`，依赖 ES2022 默认值

### 1.2 经验节点在图谱中过小

- **现象**：experience 类型节点的图标和文字明显小于其他类型，基本看不清晰
- **根因**：`nodeRadius = Math.max(5, Math.min(20, Math.sqrt(inDegree + 1) * 3.5))`。experience 节点通常 inDegree=0，得到最小半径 5px。concept 节点 inDegree 可能 5-15，半径 8-14px。视觉差异巨大。
- **修复**：为不同类型设置不同的最小半径
  - experience: 最小 12px（经验卡片是高价值内容，不应被埋没）
  - source: 最小 10px
  - concept: 最小 7px（当前 5px 略小）
  - entity: 最小 7px

### 1.3 领域分类缺少经验类型筛选

- **现象**：CategoryTree 只列出 8 个领域，无法按"经验"类型快速查找
- **根因**："experience" 是 PageType 不是 Domain。经验卡片物理上属于各领域目录下的 `experiences/` 子目录，但用户希望快速定位所有经验卡片。
- **修复**：在 CategoryTree 领域列表下方新增"按类型筛选"区块，提供 concept/entity/source/experience 四个类型过滤按钮，点击后图谱只显示该类型节点

### 1.4 LLM 集成功能未实现完整

- **现象**：用户填写了 DeepSeek API key 但无法看到连接状态、无法选择模型
- **根因**：ADR-013 D2 明确将 LLM 集成延迟到 P5。当前 SettingsPanel 仅为 UI 占位：
  - API Key 仅存 React useState（不持久化、不使用）
  - 无连接测试功能
  - 无模型选择（只有三态模式）
  - 默认模式为 cloud-first（ADR-013 V2 要求默认 disabled）
  - 无隐私告知（ADR-013 V4 要求 cloud 模式显示隐私提示）
  - 无 DeepSeek 选项
- **修复**（P4 范围内的 UX 完善，非 P5 LLM 接入）：
  1. 默认模式改为 `disabled`（ADR-013 V2）
  2. 添加 "P5 待实现" 状态徽章
  3. cloud-first 模式下添加 DeepSeek 选项和隐私告知（ADR-013 V4）
  4. 添加"测试连接"按钮，点击显示"LLM 功能将在 P5 实现"提示
  5. API Key 输入框添加"不会保存"提示
